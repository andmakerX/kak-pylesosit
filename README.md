# HTV — дневник разработки

Приложение для телефона об игре «Как пылесосить»: страница, которая ставится на экран «Домой»
и живёт вкладками — лента обновлений, всё об игре, планы, факт дня и приколы. Умеет присылать
уведомления о новом в игре.

Здесь только выложенная копия. Страница, журнал изменений и планы живут в основном репозитории
игры и приезжают сюда сами после каждого слияния в `main` (скрипт `Tools/news.ps1`), поэтому
правки руками в этом репозитории затрутся при следующей выкладке.
