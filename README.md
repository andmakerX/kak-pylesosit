# HTV — дневник разработки

Лента новостей игры «Как пылесосить» для телефона: страница, которая ставится на экран «Домой»
как приложение и показывает, что нового в игре.

Здесь только выложенная копия. Страница и журнал изменений живут в основном репозитории игры и
приезжают сюда сами после каждого слияния в `main` (скрипт `Tools/news.ps1`), поэтому правки
руками в этом репозитории затрутся при следующей выкладке.
